## Бот для поиска источников изображений в интернете
Telegram бот на основе Aiogram 3.26, от пользователя принимает только сообщения с одиночными изображениями. 

В ответ присылает результаты поиска в виде ссылок на сайты-источники в виде Inline клавиатуры с кнопками.

Результаты сохраняются в БД для избежания повторных запросов по одной и той же картинке (к примеру, из одного и того же пересланного сообщения).

Есть лимиты на API-запросы пользователя в день.

### Зачем?
Ориентировано на поиск автора или первоисточника digital-рисунков.

1. Дизайнерам/художникам (ищут референсы в хорошем качестве).
2. Админам каналов (хотят честно указывать авторов контента).
3. Коллекционерам (хотят найти в хорошем качестве или подписаться на автора).

### .env
Для работы необходим .env файл, пример заполнения которого в .env.example.

### Работа поисковика
Проходит в цикле по заданному списку сайтов-поисковиков, пока не найдет какие-либо источники.
На текущий момент это:
1. Danbooru IQDB (основной)
2. SauceNao (вспомогательный, т.к. имеет устаревшую БД)

Если источники не найдены, или пользователя не удовлетворят результаты, есть доп. кнопки:
1. "Искать ещё" - запускает поиск по следующему сайту-поисковику, если остались неиспользованные варианты.
2. "Повторить последний поиск" - повторно ищет по последнему сайту-посковику.
3. "Искать везде заново" - сбрасывает результаты и проходится по циклу заново.

### Запуск
```
docker compose up -d
```
